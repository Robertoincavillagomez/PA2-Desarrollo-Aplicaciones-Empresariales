Inventario Service

API REST académica con Jakarta EE 11, WildFly 41, Java 21 y SQL Server Express 2025.

  • GET /api/inventario/productos
  • GET /api/inventario/productos/{id}/stock
  • POST /api/inventario/productos/{id}/reservas
  • GET /api/inventario/productos/codigo/{codigo}/stock
  • POST /api/inventario/productos/codigo/{codigo}/reservas

Use el archivo requests/inventario-service.http para probar la API.
